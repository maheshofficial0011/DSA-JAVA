# Complexity Cheat Sheet

| Complexity | Typical example |
|---|---|
| O(1) | Direct array access |
| O(log n) | Binary search |
| O(n) | Single traversal |
| O(n log n) | Efficient comparison sorting |
| O(n²) | Nested loops |
| O(2ⁿ) | Many brute-force recursive subset problems |
| O(n!) | Brute-force permutations |

## Space

Distinguish input space from auxiliary space. In-place array algorithms such as two-pointer reversal can use O(1) auxiliary space.
