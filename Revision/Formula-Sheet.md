# Formula Sheet — Day 1

## Array Basics

- First index = 0
- Last index = n - 1
- Number of elements = n
- Java array length = `array.length`

## Conditions

```java
number % 2 == 0   // even
number % 2 != 0   // odd
```

## Reverse

```java
while (left < right)
```

Swap values, then move `left++` and `right--`.

## Complexity

Single traversal = O(n)  
Nested traversal = O(n²)
