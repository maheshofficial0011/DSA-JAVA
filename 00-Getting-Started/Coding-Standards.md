# Java DSA Coding Standards

## Naming

Use descriptive camelCase names such as `largest`, `secondLargest`, `left`, `right`, and `hasSecondLargest`.

## Formatting

Use consistent indentation and braces.

## Classes

Use PascalCase for class names.

## Comments

Comments should explain non-obvious reasoning, not obvious syntax.

## Complexity

Every significant solution should document time complexity and auxiliary-space complexity.

## Testing

Test normal input, small input, duplicates, negative values and boundary values where relevant.
