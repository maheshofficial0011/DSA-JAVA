# How to Use This Repository

This repository is both a DSA study system and a record of the learning journey.

## Daily Flow

1. Learn the concept.
2. Attempt the problem without copying.
3. Dry-run the approach.
4. Implement in Java.
5. Test normal and edge cases.
6. Analyze time and auxiliary-space complexity.
7. Debug mistakes.
8. Record the lesson.
9. Update progress.

## Before Looking at a Solution

Ask:

- What is the input?
- What is the output?
- What information must be tracked?
- What is the simplest correct approach?
- What is its complexity?
- Can it be improved?

## Repository Rule

The goal is understanding, not collecting code.
