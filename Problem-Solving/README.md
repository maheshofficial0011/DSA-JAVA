# Problem Solving

This section stores complete problem records separately from topic implementations.

## Standard Problem Record

```text
Problem/
├── Problem.md
├── Thought-Process.md
├── Brute-Force.md
├── Optimized-Approach.md
├── Dry-Run.md
├── Solution.java
├── Complexity.md
├── Edge-Cases.md
└── Mistakes.md
```

Small problems do not need every file. Use only what improves understanding.
