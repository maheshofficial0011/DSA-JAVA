## What I Learned

- DSA means Data Structures + Algorithms.
- Big-O describes growth as input size grows.
- Java arrays use zero-based indexing.
- Last index = n - 1.
- `.length` gives the number of elements.
- Max/min can be solved with one traversal.
- Sum/count use an accumulator.
- In-place reversal uses two pointers.
- O(n/2) simplifies to O(n).
- Second-largest distinct is a one-pass invariant problem.

## Problems

| Problem | Result | Complexity |
|---|---|---|
| Find Maximum | ✅ | O(n), O(1) auxiliary |
| Find Minimum | ✅ | O(n), O(1) auxiliary |
| Sum | ✅ | O(n), O(1) auxiliary |
| Count Even | ✅ | O(n), O(1) auxiliary |
| Reverse Array | ✅ | O(n), O(1) auxiliary |
| Second Largest Distinct | ✅ | O(n), O(1) auxiliary |

## Edge Cases

- Duplicate largest values
- All equal values
- Negative values
- `Integer.MIN_VALUE`
- Arrays with too few elements

## Reflection

The main lesson was to understand the state of variables during every iteration instead of only memorizing syntax.
