# Day 1 — DSA & Big-O Concepts

## What is DSA?

DSA stands for Data Structures & Algorithms.

- Data Structure: a way of organizing and storing data.
- Algorithm: a step-by-step procedure for solving a problem.

## Common Time Complexities

| Complexity | Typical example |
|---|---|
| O(1) | Constant time |
| O(log n) | Binary search |
| O(n) | One array traversal |
| O(n log n) | Efficient comparison sorting |
| O(n²) | Nested loops |
| O(2ⁿ) | Many brute-force recursive solutions |
| O(n!) | Brute-force permutations |

## Important Rule

Big-O describes how work grows as input size grows. It is not simply the number of operations for one fixed input.

## Space Complexity

Distinguish input space from auxiliary space. An in-place array reversal uses O(1) auxiliary space.
