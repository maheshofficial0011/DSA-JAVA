# Day 1 — Problem-Solving Framework

1. Understand the problem.
2. Create a small example.
3. Think of a brute-force approach.
4. Analyze time and space.
5. Look for a better pattern or invariant.
6. Code.
7. Test normal and edge cases.
8. Debug the exact cause of failure.
9. Record the lesson.

## Questions to Ask

- What information must be tracked?
- How does that information change each iteration?
- What invariant remains true?
- What are the edge cases?
