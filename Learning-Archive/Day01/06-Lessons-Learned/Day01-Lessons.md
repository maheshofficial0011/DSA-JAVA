# Day 1 — Lessons Learned

## Technical Lessons

- Array indexes start at 0.
- The last array index is length - 1.
- Max/min should be initialized from actual input when appropriate.
- Single-pass traversal is often enough for basic array statistics.
- Two pointers can reverse an array in place.
- Constants are ignored in Big-O.
- Auxiliary space and input space are different.
- A boolean can represent whether a valid candidate has been found.

## Problem-Solving Lesson

The important improvement was learning to maintain a clear state while processing the input instead of only focusing on syntax.

## Personal Rule

Understand the invariant before trying to optimize the code.
