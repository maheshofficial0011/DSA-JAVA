# DSA Patterns

Patterns are reusable ways of thinking that appear across many problems.

## Pattern Library

- Two Pointers
- Sliding Window
- Prefix Sum
- Fast/Slow Pointers
- Binary Search
- Monotonic Stack
- BFS
- DFS
- Backtracking
- Dynamic Programming

Each pattern can eventually contain Concept, When-To-Use, Template, Examples and Common-Mistakes notes.
